UW Schedule Exporter

Turn your University of Waterloo Quest class schedule into a calendar file (.ics) for Google Calendar, Outlook, Apple Calendar or any calendar app.

Export your schedule

  1. Sign in to Quest and open Class Schedule.
  2. Make sure List View is selected, then select the whole page (Ctrl+A, or ⌘+A on a Mac) and copy it (Ctrl+C / ⌘+C).
  3. Paste it below and click Download calendar.
  4. Import the file into your calendar app (how).

Paste everything; the exporter finds the classes itself. Classes without a set time (for example online ones) are left out.

Import into your calendar

Tip: create a new calendar for the term first and import into that, so you can remove everything at once if needed.

Google Calendar

On a computer, open Settings, choose Import & export, select the downloaded file and the calendar to add it to, then click Import.

Outlook

In the calendar, choose Add calendar, then Upload from file, and pick the downloaded file.

Apple Calendar

On a Mac, choose File › Import. On iPhone or iPad, open the downloaded file and tap Add All.

Questions

Is my schedule stored anywhere?

No. Your schedule is sent to the server only to build the calendar file, which comes straight back to your browser. The app doesn't save it. Your template settings are remembered in your own browser.

Which calendar apps does it work with?

Any app that can import an iCalendar (.ics) file, including Google Calendar, Outlook, Apple Calendar and Thunderbird. Classes repeat weekly in Toronto time until their end date.

Why are some classes missing?

Classes with no scheduled time in Quest (shown as TBA, for example online classes) can't be placed on a calendar, so they're left out.

It didn't work. What can I do?

Make sure you copied the whole Class Schedule page in List View. If it still fails, please report the problem on GitHub. Don't paste your schedule into a public issue; the form explains how to send it privately.

Is this an official University of Waterloo tool?

No. It's an independent, open-source project, not affiliated with or endorsed by the University of Waterloo.
